Política de Privacidade

Atualizada em 5 de outubro de 2026.

O Estúdio do Eco é uma ferramenta pessoal, usada apenas pelo dono das contas conectadas, no computador dele.

Quais dados são acessados

Com a autorização do dono da conta, e apenas para leitura:

  • YouTube (YouTube Data API e YouTube Analytics API): dados do próprio canal, a lista de vídeos e os números de cada vídeo.
  • TikTok: dados básicos do perfil, a lista de vídeos e os números de cada vídeo.

O Estúdio do Eco não publica, não altera e não apaga nada nas contas.

Onde os dados ficam

Os números são guardados num banco de dados local, no computador do dono. As chaves de acesso ficam no Gerenciador de Credenciais do Windows desse mesmo computador. Nada é enviado a servidores do Estúdio do Eco (não existe nenhum), nada é vendido ou compartilhado com terceiros e nada é usado para publicidade.

Como revogar o acesso

  • Google/YouTube: em myaccount.google.com/permissions, remova o acesso do Estúdio do Eco.
  • TikTok: no aplicativo, em Configurações e privacidade → Segurança → Apps e serviços autorizados.

Ao revogar, o Estúdio do Eco deixa de conseguir ler as contas. Os números já guardados ficam só no computador do dono, que pode apagá-los quando quiser.

Uso de dados do Google

O uso e a transferência de informações recebidas das APIs do Google seguem a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de Uso Limitado.
